# Site: Ressonância Magnética & Ondas de Rádio

Projeto estático em HTML e CSS. Não precisa instalar programas nem configurar comandos de build.

## Arquivo principal
- `index.html` — página completa do site.

## Publicação
1. Crie um repositório no GitHub e envie `index.html`.
2. Entre em https://vercel.com e conecte sua conta GitHub.
3. Importe o repositório e clique em Deploy.
4. O Vercel fornecerá um endereço público.

Consulte `Guia_de_Hospedagem.pdf` que acompanha o pacote para o passo a passo ilustrado por etapas.
